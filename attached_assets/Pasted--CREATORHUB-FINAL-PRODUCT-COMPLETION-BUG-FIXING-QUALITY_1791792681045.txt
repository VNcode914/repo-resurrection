Your priority is to **inspect, repair, integrate, and test the existing application** before adding anything new.

## 3. ESTABLISH ONE RELIABLE SOURCE OF TRUTH FOR CONTENT

This is the most important functional requirement.

Ideas, Calendar, Today's Content, content details, and related Tasks must use a shared, consistent data model. They must not each maintain separate copies of the same content.

Inspect the current implementation and consolidate duplicate state where necessary.

- Title.
- Optional description.
- Platform, if applicable.
- Status.
- Scheduled date/time, if applicable.
- Created timestamp.
- Updated timestamp.

When a content item changes on one page, the changes must appear everywhere that item is displayed, without requiring a manual page refresh.

**Idea → Planned → In Progress → In Review → Published**

- Moving content between workflow stages updates the existing record.

- Deleting or archiving content must be handled consistently across the application.
